## Pele Editor 1.2.0 — Diagram animations and Android export

- Add **Animate…** to the diagram menu, with Gentle rise, Slide in, Spring pop, Soft fade, and Middle out entrances.
- Preview animations with duration, repeat, and background controls. Middle out starts at a mindmap’s root and spreads toward the outer nodes; other diagrams reveal from their content’s center.
- Export animated SVG, transparent animated PNG, and MP4 video where the device provides a compatible encoder. MP4 uses a solid or theme background.
- Default export filenames to the diagram title, with the root label for untitled mindmaps.
- Default the animation background to **Match Obsidian** and the format to **Video** where supported.
- Improve Android export with **Save to device** in **Documents/Pele Editor**, **Open with…**, and **Save to vault**.

Requires Obsidian 1.15.0 or later. Animation playback and supported file types vary by receiving app.
